Core Web Vitals

Tres mètriques, tres llindars de “good”

LCP

≤ 2,5 s

Largest Contentful Paint: quan es pinta l’element més gran

CLS

≤ 0,1

Cumulative Layout Shift: quant es desplaça el contingut

INP

≤ 200 ms

Interaction to Next Paint: quant triga a respondre a una interacció

Els llindars que retorna WebPerf Snippets a cada mesura, els de Google per al percentil 75

LCP

L’LCP es descompon en quatre fases

TTFB
Retard de càrrega
Temps de càrrega
Retard de render
  • TTFB: fins que arriba el primer byte de l’HTML
  • Retard de càrrega: fins que el navegador comença a demanar el recurs de l’LCP
  • Temps de càrrega: el que triga a descarregar-se
  • Retard de render: des que arriba fins que es pinta

CLS

No tots els desplaçaments compten

Compten

Els que la persona no ha provocat: un bàner que entra sense espai reservat, una font que canvia de mida en carregar

No compten

Els que arriben just després d’una interacció, com un panell que s’obre en fer clic

Per arreglar-ho no n’hi ha prou amb el número: cal saber quins nodes es mouen

INP y LoAF

Una interacció té tres fases

Retard d’entrada

El fil principal està ocupat i l’esdeveniment espera

Processament

S’executen els handlers de l’esdeveniment

Retard de presentació

Fins que el navegador pinta el frame següent

Long Animation Frames (LoAF): anomenen l’script que bloqueja i qui l’invoca. Un trace del clic anomena la funció

Navigator, CLS i LoAF/INP

Pas 4

El Judge

Escrius

  • lcpFacts, clsFacts i inpFacts a findings.ts
  • Els fets que avalen l’explicació

Sense MCP

  • Regles sobre els JSON dels subagents
  • L’LLM no veu aquests fets: el seu prompt és el del benchmark
docker compose run --rm agents npm run check -- step-04

Pas 5

El gate al CI de cada pull request

for branch in pr-lcp-hero-lazy pr-cls-promo-banner pr-loaf-cart-handler pr-noop-refactor; do
  CANDIDATE=$branch docker compose run --rm -e OUT=/out/ci/$branch ci
  echo "$branch: exit $?"
done

Tres fallades i un pass. Llegeix el report.md de cada branca: el veredicte, l’explicació i el que l’avala

Si et quedes enrere

Cada pas té la seva solució

git checkout step-02-solution -- agents/src

Els tags de step-01-solution a step-04-solution porten el codi del pas resolt. El pas 5 funciona encara que no hagis escrit res
