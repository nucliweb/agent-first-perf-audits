## Qué construimos

<CardGrid>
  <Card title="Subagentes con MCP" icon="rocket">
    Navigator, LCP, CLS y LoAF/INP recorren la tienda con Chrome DevTools MCP y WebPerf Snippets MCP, y devuelven JSON.
  </Card>
  <Card title="Un Judge que se puede defender" icon="approve-check">
    La CLI de WebPerf Snippets da el veredicto con estadística; trace-engine-cli nombra la función; un modelo local solo explica la causa.
  </Card>
  <Card title="Un gate en el CI" icon="setting">
    El servicio `ci` compara cada rama con `main` y sale con 0 o 1, con un informe y un handoff para otro agente.
  </Card>
  <Card title="Todo en tu portátil" icon="laptop">
    Docker Compose, sin salida a internet ni claves de API. Con poca memoria, el perfil `lite` deja la explicación a un agente de tu elección.
  </Card>
</CardGrid>
