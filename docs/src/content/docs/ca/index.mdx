## Què construïm

<CardGrid>
  <Card title="Subagents amb MCP" icon="rocket">
    Navigator, LCP, CLS i LoAF/INP recorren la botiga amb Chrome DevTools MCP i WebPerf Snippets MCP, i retornen JSON.
  </Card>
  <Card title="Un Judge que es pot defensar" icon="approve-check">
    La CLI de WebPerf Snippets dona el veredicte amb estadística; trace-engine-cli anomena la funció; un model local només n'explica la causa.
  </Card>
  <Card title="Un gate al CI" icon="setting">
    El servei `ci` compara cada branca amb `main` i surt amb 0 o 1, amb un informe i un handoff per a un altre agent.
  </Card>
  <Card title="Tot al teu portàtil" icon="laptop">
    Docker Compose, sense sortida a internet ni claus d'API. Amb poca memòria, el perfil `lite` deixa l'explicació a un agent que triïs.
  </Card>
</CardGrid>
